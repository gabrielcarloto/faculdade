# Faculdade

Trabalhos e exercícios do curso de Sistemas de Informação (BSI), organizados por disciplina. O repo reúne C, C++, Go, Python, TypeScript, NASM e HTML/CSS.

## Disciplinas

- [Desenvolvimento Integrado de Sistemas](./Desenvolvimento%20Integrado%20de%20Sistemas/) — Go: solver de reconstrução de imagem (gradiente conjugado) com cache e agendador
- [Estruturas de Dados](./Estruturas%20de%20Dados/) — C++: TADs genéricos de lista (List, SortedList, Vector) com menu e profiler
- [Estruturas de Dados 2](./Estruturas%20de%20Dados%202/) — C/C++: árvores (AVL, binárias, tries), heaps, hash tables e grafos
- [Fundamentos de Programação](./Fundamentos%20de%20Programação/) — C: exercícios semanais das aulas de introdução à programação
- [Padrões Web](./Padrões%20Web/) — HTML/CSS/JS: páginas estáticas, formulários e tabelas
- [Processamento Digital de Imagens (PDI)](./Processamento%20Digital%20de%20Imagens%20%28PDI%29/) — Python + OpenCV: filtros, blur, chroma key, segmentação e contagem de arroz
- [Redes de Computadores](./Redes%20de%20Computadores/) — Go + TypeScript: transferência de arquivos por TCP e UDP, servidor HTTP próprio
- [Técnicas de Programação](./Técnicas%20de%20Programação/) — C/C++: orientação a objetos, modelagem de universidade e resolução de provas
- [Arquitetura e Organização de Computadores](./Arquitetura%20e%20Organização%20de%20Computadores/) — Assembly NASM x86-64: hello world, fibonacci, sub-rotinas de print/atoi
